# Catalog image coverage

Revision: `2026-10-09-detail-images`

Selected and availability-checked: **1295 of 1,458 artists**, **78 of 94 venues**.

Every artist and venue was included in discovery. Remaining records are intentionally blank: available pages did not provide a confidently matched usable image, returned access errors, or supplied only unrelated graphics/maps. This is incomplete image coverage, not a claim that no image exists online.

Images are remote URLs. They may change or disappear; the UI falls back to the venue on concerts and hides failed images elsewhere. Source pages and selection basis are recorded in `detail-images-sources.json`.

Import behavior: writes only image fields through a reviewed catalog revision. Names and existing image values/absence are preconditions; later admin edits are preserved by the deployment receipt. There are no new database documents or app reads.
